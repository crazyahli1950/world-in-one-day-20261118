A deterministic Python program (Pillow) that draws a complete newspaper front page — "THE WORLD IN ONE DAY" — summing up the world news of Wednesday 18 November 2026 in a single 1024×1024 PNG: the Shenzhen Trump–Xi–Putin trilateral summit, the Gulf and Strait of Hormuz escalation, Nvidia's $115.8 billion quarter, Ukraine's Crimea Bridge strike, the US losing measles-free status, the $6.3B Binance hack, and a markets ticker. No network, no randomness: the same bytes on every run.

## Run it

```sh
pip install pillow
python3 main.py
```

Writes the entry image to /output/entry.png (or ./entry.png when /output does not exist).
